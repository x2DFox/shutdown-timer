# ShutdownTimer
Минималистичная утилита с открытым исходным кодом, которая делает ровно одну вещь, но делает ее отлично: выключает компьютер по таймеру. Никаких лишних настроек, фоновых процессов и установщиков - просто запустил и выставил время.
